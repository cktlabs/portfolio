# News Collider — automated news annotation

> Entity extraction, event detection, and multi-label text categorization.

## Business problem

News analysis needs entity extraction, event detection, and assigning multiple categories to texts.

## What we built

An NLP system using transformer models. The public case describes a joint project with MSU CMC.

**Workflow:** Text → entities and events → categories for further analysis.

## When this experience is relevant

Products requiring search, classification, or structured extraction from text collections.

## Technical foundation

PyTorch · Transformers · FastAPI · React.
