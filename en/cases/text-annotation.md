# Text Annotation — data annotation platform

> Published operating scope: **1,000+ texts per day**, with annotation quality controls.

## Business problem

Text annotation requires work distribution, quality control, and preparing data for downstream use.

## What we built

A distributed annotation platform with inter-annotator agreement metrics, guideline enforcement, and data export pipelines.

**Workflow:** Task assignment → annotation → quality control → export.

## When this experience is relevant

Teams organizing annotation, review, or ML data preparation workflows.

## Technical foundation

FastAPI · React · PostgreSQL · Docker.
