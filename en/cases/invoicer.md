# Invoicer — invoice processing automation

> The published case reports an **80% reduction in manual processing time** for the client.

## Business problem

Invoice processing requires extracting fields, validating data, and transferring information into the accounting system.

## What we built

AI-assisted document extraction with invoice recognition, validation, and integration with 1C.

**Workflow:** Data extraction → validation → accounting system integration.

## When this experience is relevant

Teams manually processing documents or transferring information into an ERP.

## Technical foundation

FastAPI · PostgreSQL · React · 1C.
