# Phisher — staff security awareness training

> **400+ attack templates** and a shared platform for running training campaigns and analyzing results.

## Business problem

A company needs to run phishing simulations and understand how employees recognize attacks.

## What we built

A phishing simulation platform with campaign management, analytics, and automated reporting.

**Workflow:** Prepare a campaign → run a simulation → measure responses → report.

## When this experience is relevant

Organizations building security training or security workflow platforms.

## Technical foundation

Python · FastAPI · React · PostgreSQL.
