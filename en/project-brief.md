# A short project brief

A free-form message is fine. You do not need to answer every question.

1. **Goal:** what should change for the business or its users?
2. **Current process:** what is in place and where is the main difficulty?
3. **Integrations:** which systems and data sources already exist?
4. **Constraints:** timing, security requirements, and an indicative budget if known.
5. **Contact:** who should we talk to and how?

## Example opening message

> We need to automate incoming invoice processing and transfer data into our accounting system. Staff currently enter invoice fields manually. We would like to discuss the integration, delivery stages, and an estimate. We can share document formats and process details after an NDA.
