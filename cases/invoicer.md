# Invoicer — автоматизация обработки счетов

> В опубликованном кейсе время ручной обработки для клиента сократилось на **80%**.

## Задача

Обработка счетов требует извлечения реквизитов, проверки данных и переноса информации в учётную систему.

## Что сделали

Система AI-извлечения данных из документов с распознаванием, валидацией и интеграцией с 1С.

**Сценарий работы:** Извлечение данных → проверка → передача в учётную систему.

## Когда этот опыт полезен вам

Если ваша команда вручную обрабатывает документы или переносит данные в ERP.

## Техническая основа

FastAPI · PostgreSQL · React · 1C.
