# Finder — бронирование и поддержка клиентов

> Бронирование, рекомендации и обращения в поддержку объединены в одном продукте.

## Задача

Для бронирования нужны актуальные свободные места, обработка запросов клиентов и информация для управляющих.

## Что сделали

Платформа бронирования ресторанов со свободными столами в реальном времени, аналитической панелью и ML-чатботом.

**Сценарий работы:** Доступность в реальном времени → бронь → поддержка клиента → аналитика.

## Когда этот опыт полезен вам

Если вы создаёте сервис бронирования или цифровой продукт с постоянным взаимодействием с клиентами.

## Техническая основа

Python · FastAPI · React · WebSockets.
