# Text Annotation — платформа разметки данных

> Опубликованный масштаб — **1000+ текстов в день**, с контролем качества разметки.

## Задача

Процесс разметки текстов требует распределения работы, контроля качества и подготовки данных для дальнейшего использования.

## Что сделали

Распределённая платформа разметки с метриками межаннотаторского согласия, контролем гайдлайнов и экспортом данных.

**Сценарий работы:** Распределение задач → разметка → контроль качества → экспорт.

## Когда этот опыт полезен вам

Если вашей команде нужно организовать разметку, проверку или подготовку данных для ML.

## Техническая основа

FastAPI · React · PostgreSQL · Docker.
